# 0003 — MIT for the code, CC BY-SA 4.0 for the data

**Date:** not dated in the handover note; the split was in place by 2026-09-22,
when `LICENSE-DATA` was added
**Status:** accepted

## What was decided

The pipeline code and `config.yaml` are MIT. The lists, the glosses, the README,
the CHANGELOG and `DATA_SOURCES.md` are CC BY-SA 4.0.

## Why

Jim said he was "fine with the more restrictive licence" for the data. Share-alike
keeps the derived word lists open, while MIT leaves the code freely reusable.

## What it costs

Anyone redistributing the lists has to carry the same licence, which rules out some
commercial reuse. It also means two licence files and a split that has to be
explained in the README.
